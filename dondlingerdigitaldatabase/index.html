🛡️ Zero-Liability Architecture (ZLA)

ZLA decouples encryption keys from server storage. Even if databases are audited or breached, servers hold zero plaintext liability—decryption keys remain strictly on the client.

// ZLA Invariant Example
const key = await window.crypto.subtle.generateKey(...);
const ciphertext = await encrypt(payload, key);
// Server receives ONLY ciphertext (Zero Liability)
